# 戦術対抗戦 編成記録ツール(Vercel版)

ブルーアーカイブ「戦術対抗戦」の対戦編成を手入力で記録・集計するツールです。
サーバーを持たない完全な静的サイトで、Vercelにそのままデプロイできます。

元になったローカル版(Node + `data.json`保存): `/Users/kiyui/defense-comp-tracker/`
(モード分割・自分の編成欄・画像リンク修正はこちらの静的版にのみ実装済み)

## この版の特徴

- **サーバー不要**: `index.html`1枚の静的サイト。データはブラウザの`localStorage`に保存
- **対戦は「相手の編成」と「自分の編成」のセットで1レコードとして記録する**(攻撃と防衛は表裏一体のため)。
  モードは「相手がどちらの編成を使っているか」だけを選べばよく、自分側は自動的にもう片方になる:
  - 「相手の攻撃編成を記録」— 自分が防衛側。相手=攻撃編成(A1〜A4/SP1〜SP2)、自分=防衛編成(D1〜D4/SP1〜SP2)。このツールの本来の用途
  - 「相手の防衛編成を記録」— 自分が攻撃側。相手=防衛編成(D1〜D4/SP1〜SP2)、自分=攻撃編成(A1〜A4/SP1〜SP2)
  - 使用キャラ集計・ポジション別集計・相手別遭遇回数・保存済み履歴は、選択中のモードのデータだけに絞って表示される(集計対象は「相手」側の編成)
  - 保存済み履歴には相手の編成と自分の編成の両方がチップ表示される
  - 旧データ(モード分割前に保存したもの)は「相手の攻撃編成」扱いになる(このツールの元々の用途に合わせた既定値)
  - 「自分の編成」欄は保存後もクリアされず、次の対戦記録にそのまま引き継がれる(同じ編成を使い続けることが多いため)。入力するたびに自動でブラウザに記憶される
- **キャラ名・画像は[ba-timeline](https://ba-timeline.vercel.app)と共有**: `characters.json`をブラウザから直接fetch(CORS許可済み)。
  ba-timeline側でキャラを追加すれば自動的にこちらの候補・画像にも反映される
  - ba-timeline側は衣装違いキャラを半角括弧("アヤネ(水着)")、こちらの保存データは全角括弧("アヤネ（水着）")で持っているため、
    突き合わせ時に名前を正規化して揃えている(揃えていないと衣装違いキャラの画像がほぼ全滅する不具合があったため修正済み)
- 役割(ストライカー/スペシャル)の食い違い警告つき
- **キャラ名入力欄は画像つきの候補ポップアップ**(自前実装)。ネイティブの`<datalist>`は候補に画像を出せないため、
  入力に応じてキャラアイコン+名前の候補を独自に描画している。クリックまたは↑↓+Enterで選択可能
- **集計・履歴もすべてキャラアイコン表示**。アイコンの縁取り色で役割を区別する(ストライカー=ピンク / スペシャル=水色)。
  色はスロット位置ではなく**キャラ本来の役割**に基づくので、どの画面でも意味が一定
  - 保存済み履歴の編成はアイコンのみ(名前なし)で表示し、6人が横1行に収まるようにしている。
    名前はアイコンにマウスを乗せるとツールチップで出る。画面幅が狭いときはアイコンを一段小さくして1行を維持する
- ポジション別集計は各ポジションを横並びの列にし、列内は縦にキャラを積む。
  1列が16件を超えると「すべて表示」ボタンで開閉できる(既定は16件まで表示)
  - **SPはスロット位置で役割が変わらないため、SP1とSP2を「SP」として1列にまとめて集計する**
    (D1〜D4 / A1〜A4 は位置ごとに分ける)
- 相手別の遭遇回数は、名前が短く横に間延びするため複数列のグリッドに流し込んでいる
- 「すべてのデータを削除」ボタンで対戦記録と自分の編成を一括削除できる(取り消せないため確認2回)

## ローカルでの動作確認

```sh
node dev-server.js
```

→ http://localhost:3777 (ただの静的ファイルサーバー。`index.html`を直接ブラウザで開いても動く)

## Vercelへのデプロイ

1. このフォルダをGitHubリポジトリにする(未作成なら`git init`して新規リポジトリを作成・push)
2. Vercelでそのリポジトリを "Import Project"。フレームワークは検出不要("Other"のままでOK)
   - `vercel.json`で`outputDirectory: "."`を指定済みなので追加設定は不要
3. デプロイ後、本番URLで動作確認

## データについて(重要)

- 保存先は**ブラウザのlocalStorage**(このツール単体、サーバー保存なし)。
  - 端末・ブラウザが変わるとデータは引き継がれない
  - ブラウザのキャッシュ/サイトデータを消すと消える
  - → **「データのバックアップ」欄の「エクスポート」で定期的にJSONダウンロードを推奨**
- 旧ローカル版(`/Users/kiyui/defense-comp-tracker/data.json`)のデータをこちらに移したい場合:
  1. `/Users/kiyui/defense-comp-tracker/data.json`をこの画面の「インポート」で読み込む
  2. `{records:[...]}`形式・配列そのものの形式のどちらも読み込み可能。既存データとはID重複を除いてマージされる
  3. 「エクスポート」でダウンロードしたJSONは`{records, myTeamDefaults}`形式で、インポート時に自分の編成の既定値も一緒に復元される

## ファイル構成

- `index.html` — アプリ本体(入力フォーム・localStorage永続化・集計・ba-timeline連携)
- `dev-server.js` — ローカル確認用の最小静的サーバー(本番では使わない)
- `vercel.json` — Vercelを静的サイトとして扱わせるための設定
- `ogp.png` — SNS共有カード用のバナー画像(1200×630)。
  盾アイコン＋タイトル＋説明文をHTMLで組み、headless Chromeの`--screenshot`で書き出したもの。
  作り直す場合は同じ手順でこのサイズを維持すること(`<head>`の`og:image:width/height`と揃えるため)
- `favicon.ico` / `apple-touch-icon.png` — タブ・ホーム画面用の盾アイコン
  (元画像を透明部分でトリミング→正方形化して生成。`.ico`は16〜256pxを同梱)
